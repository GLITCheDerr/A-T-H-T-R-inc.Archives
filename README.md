# A-T-H-T-R-inc.Archives

**AETHR Archive Terminal - A Terminal-Based Mystery Game**

You've found an abandoned database from AETHR Inc., a secretive research 
organization that studied anomalous phenomena. The facility evacuated in 
October 2020. All personnel are missing or unaccounted for.

**Gameplay:**
- Decode Morse code to unlock the terminal
- Browse classified documents from 4 divisions (BEACON, CIPHER, PRISM)
- Piece together the timeline from corporate greed to catastrophic failure
- Discover hidden files and console commands
- Uncover what "Anomaly #742S1" really was

**Features:**
- Authentic terminal aesthetic (green-on-black, CRT feel)
- No downloads - plays in browser
- Multiple documents telling an interconnected story
- Hidden Easter eggs for dedicated investigators
- 15-30 minutes to complete (longer if you explore everything)

Free to play. Made with pure HTML/CSS/JS.
